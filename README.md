# 🌐 Plataforma ONGs Brasil

> Uma plataforma web interativa para gerenciamento e visualização de informações de ONGs, com foco em acessibilidade, SPA dinâmica e boas práticas de desenvolvimento.

---

## 🚀 Tecnologias Utilizadas
- **HTML5** – Estrutura semântica e otimizada  
- **CSS3** – Design responsivo, alto contraste e modo escuro  
- **JavaScript (ES6)** – Validação de formulários, SPA e LocalStorage  
- **Git / GitHub** – Controle de versão e GitFlow  
- **Otimização** – Minificação de arquivos e compressão de imagens  

---

## ⚙️ Funcionalidades Principais
- Navegação dinâmica por SPA (Single Page Application)  
- Validação de formulários (nome, e-mail e telefone)  
- Armazenamento de dados no LocalStorage  
- Navegação por teclado e suporte a leitores de tela  
- Modo escuro e alto contraste para acessibilidade  
- Otimização para produção: minificação e compressão de imagens  

---

## 🌿 Estrutura de Branches (GitFlow)
- `main` – Branch de produção  
- `develop` – Branch de desenvolvimento  
- `feature/*` – Novas funcionalidades  
- `release/*` – Preparação de releases  
- **Tags de versão:** `v1.0.0`
